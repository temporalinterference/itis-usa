## Directory Purposes

**assets/:**
- Purpose: Site-specific styling, typography, and visual assets
- Contains: SCSS source files, font files, logo/banner images
- Key files: `custom.scss` (brand colors, gradients, typography), `banner.jpg` (header image)

**content/cards/:**
- Purpose: All website content organized as discrete cards
- Contains: 25+ card directories, each with markdown content and optional images
- Pattern: Flat structure with consistent naming for news items (prefixed with `news-` and date)

**Card Directory Structure (example: `content/cards/history/`):**
- `index.md`: Front matter with title + brief teaser text (displayed on card grid)
- `modal.md`: Front matter with id + expanded content markdown (displayed in modal overlay)
- Optional image files: Referenced in modal.md via shortcodes
- Examples with images: `news-20250710-SPARC-Seminar/` contains news image and teaser image files

**.planning/codebase/:**
- Purpose: GSD (Guided Software Development) analysis documents
- Contains: Architecture, structure, conventions, testing, stack, and concerns documentation
- Generated by: GSD orchestrator for phase planning and code generation

**.github/workflows/:**
- Purpose: CI/CD automation
- Contains: Hugo deployment pipeline configuration
- Triggers: Git push events to main branch

**public/:**
- Purpose: Static build output (generated by Hugo build)
- Contains: HTML files, compiled CSS, JavaScript, assets
- Not committed: Listed in `.gitignore`, regenerated on each build

**resources/:**
- Purpose: Hugo cache for processed assets
- Contains: Compiled SCSS, image optimization cache
- Not committed: Generated during build process

## Key File Locations

**Entry Points:**
- `config.yaml`: Site configuration including base URL, title, theme module, parameters
- `.github/workflows/deploy-hugo.yaml`: Automated deployment to hosting

**Configuration:**
- `config.yaml`: Hugo site configuration with theme parameters, colors, fonts, card dimensions
- `mise.toml`: Development environment: Hugo 0.152.2, Dart Sass 1.93.2, Go 1.25.3
- `go.mod`: Go module dependency: `github.com/temporalinterference/z43-cards-theme v0.0.0`

**Core Logic:**
- Theme layouts: Imported via module, not in repo (at `github.com/temporalinterference/z43-cards-theme`)
- Custom styling: `assets/scss/custom.scss` (brand colors, gradients, navbar styling)
- Content schema: Defined by z43-cards-theme module via front matter patterns

**Content:**
- Card index pages: `content/cards/{card-id}/index.md` (teaser + title)
- Card modals: `content/cards/{card-id}/modal.md` (expanded content with id field)
- Card images: `content/cards/{card-id}/*.jpg`, `*.svg` (image assets)

**Testing:**
- None detected - static site generator with no automated tests

## Naming Conventions

**Files:**
- Markdown files: lowercase with hyphens (`index.md`, `modal.md`, `custom.scss`)
- Images: descriptive lowercase with hyphens (`banner.jpg`, `logo.svg`, `teaser.jpg`)
- SCSS variables: Hugo template syntax with double curly braces and pipes

**Directories:**
- Content cards: lowercase with hyphens (e.g., `publication-1`, `tissue-properties`)
- News cards: `news-` prefix followed by ISO date or event slug (e.g., `news-20250710-SPARC-Seminar`)
- Asset subdirs: Functional grouping (`fonts/`, `images/`, `scss/`)

**Card ID Format:**
- Standard cards: slug from directory name (e.g., `history`, `mission`)
- News cards: either date-based (`news-20250710-SPARC-Seminar`) or event-based
- Publication cards: numbered (`publication-1`, `publication-2`, `publication-3`)

## Where to Add New Code

**New Card (Standard Content):**
1. Create directory: `content/cards/{card-id}/`
2. Add index page: `content/cards/{card-id}/index.md` with front matter `title: [Title]` and teaser text
3. Add modal: `content/cards/{card-id}/modal.md` with front matter `id: {card-id}` and expanded markdown content
4. Add images (optional): Place `.jpg` or `.svg` files in same directory

Example structure:
```
content/cards/my-new-card/
├── index.md          # title: "My New Card" + brief description
├── modal.md          # id: my-new-card + detailed content
└── image.jpg         # Referenced in modal.md via {{< modal-image image.jpg >}}
```

**New News Item:**
1. Create directory: `content/cards/news-{YYYYMMDD}-{slug}/`
2. Add index page: `content/cards/news-{YYYYMMDD}-{slug}/index.md` with date and teaser
3. Add modal: `content/cards/news-{YYYYMMDD}-{slug}/modal.md` with id field
4. Add images: teaser image and content image files

Example:
```
content/cards/news-20260215-Announcement/
├── index.md          # title: "Announcement" + Date + teaser
├── modal.md          # id: news-20260215-Announcement + full details
├── teaser.jpg        # Small image for card grid
└── announcement-image.jpg  # Full-size image for modal
```

**Custom Styling:**
- Add overrides to: `assets/scss/custom.scss`
- Pattern: Hugo template syntax for parameters (e.g., `{{ .Site.Params.colors.emphasis }}`)
- Recompile: Hugo build automatically processes SCSS → CSS

**Brand Customization:**
- Edit `config.yaml` under `params` section:
  - Colors: `params.colors.{background, emphasis, muted, link, cardBackground, navbarBackground, offcanvasBackground}`
  - Fonts: `params.fonts.{body, heading, size, lineHeight}`
  - Card dimensions: `params.card.{width, height}`
